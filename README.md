# ♟️ Chess Game

A simple 2-player chess game built using JavaScript and chess.js.  
It supports all basic chess rules including check, checkmate, and legal move validation.

---

## 🚀 Features

- 2-player local gameplay
- Legal move validation
- Check and checkmate detection
- Move and capture sound effects
- Simple interactive board UI

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- chess.js (game logic library)

---

## 🎮 How to Play

- Click a piece to select it
- Click a valid square to move
- White starts first
- Game ends on checkmate or draw
